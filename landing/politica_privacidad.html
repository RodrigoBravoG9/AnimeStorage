Política de privacidad

Cómo se manejan los datos en la versión de demostración de AnimeStorage.

Última actualización: 19 de octubre de 2026

1. Alcance y estado del sitio

AnimeStorage es un proyecto de interfaz para descubrir series y películas de anime. Esta política describe el código de esta versión: el catálogo, el carrito y los pedidos de prueba funcionan de forma local; no hay un sistema operativo de cuentas, pagos ni reproducción. Antes de habilitar esos servicios, el responsable del sitio deberá actualizar este documento con su identidad y un canal de contacto verificable.

2. Datos del formulario de acceso

La página de acceso permite probar la validación de un correo y una contraseña de ejemplo. Su código no envía esos campos a un servidor ni los guarda en el navegador. No ingreses credenciales reales. No se crea una cuenta ni se inicia una sesión.

3. Búsquedas y navegación

Los filtros del catálogo se procesan en el navegador. El código del catálogo no envía las búsquedas ni conserva un historial de títulos consultados. El proveedor que aloje el sitio puede procesar datos técnicos de las solicitudes, como dirección IP y tipo de navegador, según su configuración.

4. Almacenamiento local

El código de la página de inicio contempla una preferencia en localStorage para recordar si se descartó un aviso de newsletter. Su uso depende de que el aviso esté presente. El catálogo, el carrito, los precios administrados y los pedidos de prueba se conservan en localStorage bajo animestorage.database.v1. Se comparten entre páginas y pestañas del mismo origen en este navegador; no se envían a un servidor. El panel Admin es de acceso público y modifica esos datos locales. Las páginas no almacenan credenciales. Al borrar los datos del sitio se pierden los cambios y pedidos locales. Puedes borrar los datos del sitio desde la configuración del navegador.

5. Recursos y sitios de terceros

La hoja de estilos solicita la fuente Inter a Google Fonts. La página de inicio también referencia recursos externos de jsDelivr, cdnjs y Cloudflare, incluido un script de medición de Cloudflare. Al cargar recursos externos, esos proveedores pueden recibir datos técnicos de conexión; su tratamiento depende de sus propias políticas y de la configuración del servicio.

Los enlaces a redes sociales llevan a sitios externos. Al abrirlos, se aplican sus políticas de privacidad. No representan una integración de cuentas con AnimeStorage.

6. Newsletter y futuras funciones

La página de inicio contiene código previsto para enviar un correo a una ruta de suscripción si se incorpora un formulario. Este proyecto no incluye un servicio de suscripción verificado. No debe interpretarse como una suscripción activa. Si se habilita, se deberán informar el destinatario de los datos, la finalidad, el tiempo de conservación y la forma de cancelar la suscripción.

7. Control de tus datos

Puedes explorar el catálogo sin completar el formulario de acceso y borrar el almacenamiento local desde tu navegador. Esta versión no publica un canal de solicitudes de datos personales; antes de recibir datos reales deberá incorporarse uno, junto con el procedimiento para solicitar acceso, corrección o eliminación cuando corresponda.

8. Cambios en esta política

Las funciones y los proveedores pueden cambiar durante el desarrollo. La fecha de esta página identifica esta versión del documento. Revisa la política antes de utilizar nuevas funciones que pidan datos personales.
